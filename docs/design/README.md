# System Design & Architecture

Thư mục lưu trữ tài liệu thiết kế hệ thống:
- Kiến trúc hệ thống (System Architecture)
- Biểu đồ lớp (Class Diagrams)
- Biểu đồ tuần tự (Sequence Diagrams)
- Thiết kế cơ sở dữ liệu (ERD - Entity Relationship Diagram, Data Dictionary)
- Thiết kế giao diện (UI/UX Wireframes & Mockups)
